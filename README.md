# bubble-sort-python
Implementation of the Bubble Sort algorithm using Python.
Bubble sort repeatedly compares adjacent elements and swaps them if they are in the wrong order. After each pass, the largest unsorted element moves to the end. Its average and worst-case time complexity is O(n²), and its space complexity is O(1)
# working of bubble sort
[5, 2, 8, 1, 3]

Compare 5 and 2 → swap
[2, 5, 8, 1, 3]

Compare 5 and 8 → don't swap
[2, 5, 8, 1, 3]

Compare 8 and 1 → swap
